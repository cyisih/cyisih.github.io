## 📊 Featured Project: Global Climate & Economic Analysis

For my capstone project, I combined global weather patterns with economic data to identify optimal regions for living and resource allocation.

### 🎯 Objective
To find affordable world cities that maintain warm winter temperatures (above 60°F) using relational data structures.

### 💡 Key SQL Skills Demonstrated
* **Multi-Table JOINs:** Linked global weather metrics to economic cost-of-living indices.
* **CTEs & Window Functions:** Partitioned and ranked cities dynamically based on affordability metrics.
* **Data Cleaning:** Handled missing temperature values using conditional logical scripts.

### 🔍 Key Insights Found
* Isolated three specific cities in Southeast Asia that offer a 40% lower cost of living while matching premium Mediterranean winter climates.
